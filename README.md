# 小小心愿｜生日心愿单原型

一个无需安装、无需登录的纯 HTML/CSS/JavaScript 网页原型，数据保存在当前浏览器的 `localStorage`。

## 打开方式

直接用现代浏览器打开 `index.html` 即可。若浏览器限制本地文件的剪贴板访问，可通过本地静态服务器打开，例如在此目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。部署时将 `index.html` 放到任意静态网页托管服务即可；没有构建步骤，也没有服务器端数据表。

## 演示路径

1. 首页输入心愿主昵称并创建清单。
2. 添加礼物名称和预估金额；购买链接、图片链接、备注、优先级可按需补充。
3. 复制访客链接，打开后无需填写任何信息即可浏览。
4. 清单直接显示“未拍下”“已拍下”或“已感谢”。
5. 点击未拍下条目的“拍下”，访客看到“已拍下”，同一条目不能再次拍下；拍下者可在拍下它的同一浏览器中点击“撤销拍下”。
6. 回到管理链接，心愿主可编辑/删除条目，标记“已收到”；送礼者会看到“已感谢”。

## 原型边界

- 管理链接使用随机口令参数保护管理页面；持有管理链接的人可以管理清单，请妥善保存。
- 数据只存在于当前浏览器的 `localStorage`，清除浏览器数据会删除清单。访客链接可以在同一浏览器的其他标签页中共享状态，但不会让不同设备/浏览器自动同步。多人跨设备真实共享需要接入后端存储。
- 访客无需提供个人信息。撤销拍下通过当前浏览器生成的匿名标识识别，因此需在拍下礼物的同一浏览器和设备上撤销；清除站点数据会移除该标识。
- 本原型不含账号、支付、物流或任何多人合送/分摊功能。
